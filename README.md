# PyData Academy — Python for Data Analysis

A responsive, single-file interactive web application for learning Python for data analysis from zero to hero.

## Modules Covered
1. **Python Fundamentals for Analytics**: Dynamic typing, collections, list comprehensions, functions, lambdas, file I/O.
2. **NumPy Foundation**: Multi-axis slicing, vectorization, broadcasting, matrix algebra.
3. **pandas Wrangling**: DataFrames, indexing (.loc vs .iloc), cleaning, aggregations, merges.
4. **Data Visualization**: Matplotlib subplots, Seaborn statistical plots, correlation heatmaps.
5. **scikit-learn Modeling**: Preprocessing, linear regression, random forest classification, k-means clustering.
6. **Capstone Projects**: Customer churn prediction, climate time-series analysis, and quantitative portfolio risk.

## Live Deployment (GitHub Pages)
1. Fork or upload this repository to GitHub.
2. Go to **Settings** > **Pages**.
3. Under **Branch**, select `main` and root `/`, then click **Save**.
